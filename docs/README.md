# docs

Build notes, analyses and write-ups, written in Markdown.

## Conventions

- One file per topic, numbered in the order of the learning plan, for example
  `01-regulations.md`, `02-build-5inch.md`, `05-pid-tuning.md`.
- Images go in `docs/images/`, named after the document they belong to,
  for example `02-build-5inch-stack-wiring.jpg`.
- Screenshots and diagrams are saved as PNG or SVG. Photos as JPG (stored with Git LFS).
- Link to logs, configuration and test data with relative paths instead of copying them here.
