# sitl

Software-in-the-loop setup and test scenarios.

Running the real flight controller firmware on a PC against a simulated physics model,
to test firmware changes and autonomous flight modes before flashing them to hardware.

## Planned contents

- Setup instructions for INAV and ArduPilot SITL
- Scripts for starting the simulator and firmware together
- Test scenarios, for example GPS rescue, position hold and failsafe behaviour
- Results compared with real flight logs in `logs/`
